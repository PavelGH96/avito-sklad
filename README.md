# Склад Авито · товары для сна

Складской учёт для торговли на Авито: карточки товаров, остатки, сделки, покупатели, сводка.
Один файл `index.html` + PWA (manifest, service worker). База — Supabase (проект WiseWallet, таблицы `sklad_*`).

- Несколько магазинов Авито с общим остатком: у товара своё объявление и цена в каждом магазине, у сделки — магазин.
- Вход по email и паролю. Первый вошедший становится владельцем склада.
- Доступ помощникам — по email в разделе «Аккаунт и доступ» (кнопка с буквой в шапке).
- Хостинг: GitHub Pages → Settings → Pages → Deploy from branch `main` / root.
